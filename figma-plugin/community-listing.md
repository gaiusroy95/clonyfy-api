## Name

Clonyfy Import

## Tagline

Import Clonyfy page exports as editable Figma layers

## Description

Clonyfy Import turns a Clonyfy **Scene Graph** export into native Figma layers (frames, rectangles, text, images, gradients, and borders).

### How to use

1. In [Clonyfy](https://clonyfy.com), open a cloned page and choose **Export to Figma → Export for Figma Desktop**.
2. The Scene Graph JSON is copied to your clipboard (and can open your Figma file).
3. In Figma, run **Plugins → Clonyfy Import**.
4. The plugin reads the clipboard and builds editable layers automatically.

### Also includes

- **Import sample** — verify the plugin without leaving Figma
- **Auto-import from clipboard** when the plugin opens (toggle in the UI)
- Works with large pages via chunked transfer
- Falls back gracefully when fonts or huge images are unavailable

### Note for Figma Web

If you prefer not to install a plugin, Clonyfy can also **Download SVG for Figma Web** — drag the SVG onto the canvas.
